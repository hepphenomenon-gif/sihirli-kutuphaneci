# 📖 Sihirli Kütüphaneci: E-Kitap Sistemi

Hoş geldiniz! Bu depo, denemelerimin ve hikayelerimin sihirli kütüphaneci tarafından düzenlendiği e-kitap projesidir.

## 📂 Dosya Yapımız

- **denemelerim/**: Kitabımızın bölümlerini barındıran oda.
- **kitap-meta.json**: Kitabımızın yazar ve ad bilgileri.
- **indeks.json**: Sihirli Kütüphanecimizin oluşturduğu indeks defteri.

## 🪄 Nasıl Çalışır?

1. Yeni bir deneme veya bölüm eklemek için `denemelerim/` klasörüne dosyanızı ekleyin.
2. GitHub Actions, Python kodumuzu çalıştırarak `indeks.json` dosyasını otomatik olarak günceller.
